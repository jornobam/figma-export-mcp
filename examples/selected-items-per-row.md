# Сценарий: разное число элементов из каждой строки

## Запрос

> Из первых двух строк скачай по четыре первых изображения, из следующих трёх — второе и последнее. Порядок в результате: сначала все вторые элементы, затем все последние.

## Требования

- Selection и ordering моделируются отдельно.
- Первая стадия выбирает позиции по per-row rules.
- Вторая стадия перестраивает итоговый порядок без изменения состава.
- `last` вычисляется относительно фактической длины конкретной строки.
- Один node ID не должен появиться дважды, если `second == last` в короткой строке; политика deduplication показывается в preview.
- Если понятие «следующие три строки» неоднозначно из-за секций, агент уточняет scope.

## Preview

Должен показывать как минимум:

- список затронутых строк;
- позиции до и после ordering;
- exact count;
- дубликаты/deduplication;
- три примера конечных имён.
